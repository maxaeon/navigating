Navigating Philosophy

About this page

A route through the history of philosophy, walked one place at a time. Every activity below is a single self-contained page that runs in the browser, records the student's written answers, and produces a report to download and submit. Start at the world map, which unlocks the route in order, or open any single activity directly from the list.

Open the world map

The route hub. It tracks which activities are complete, opens each region in order, and holds the roads between them. This is the link to give students who are walking the whole expedition.

Progress is stored in this browser, so a student who switches browsers or devices starts the map fresh. The activities themselves work in any order, and each one produces its own report.

Notes

Every page here is a single HTML file with no build step and no external dependencies, so the whole folder can be hosted as static files or opened from disk. Each folder holds its activity, a README describing what the activity covers and how to embed it, and screenshots.

To embed one activity in a course page, use an iframe pointing at that file, for example <iframe src="prologue/philosophy_prologue.html" width="960" height="1000"></iframe>. To assign the whole route, link students to this page or to the world map.
